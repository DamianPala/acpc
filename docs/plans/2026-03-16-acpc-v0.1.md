# Plan: acpc v0.1 - Python ACP CLI Client

Thin CLI wrapper over official ACP Python SDK. First headless Python CLI for ACP.

## 1. Scope

**Commands:** `prompt` (+ `run` alias), `agents`, `sessions`, `install`, `stop`, `status`

**Features:**
- TOML agent registry (codex, claude built-in, user-extensible via platform config dir)
- Multi-turn sessions via ACP `session/load`. If unsupported: `--last`/`-s` exit 1 with clear error, never silently start new session
- Model/mode selection (`--model`, `--mode`)
- Permission policy (`--permissions all|write|read|none|prompt`)
- Output modes: text, NDJSON (ACP passthrough), quiet, file
- Input: positional arg, `--input-file`, stdin pipe (`-`)
- Process management: PID-based `stop`, `status`
- Shell completions (click built-in + `generate-completion` subcommand)

**Not in scope:** TUI, GUI, MCP bridge, binary output, `--env` filtering, persistent adapter connections (v0.2)

**Deps:** `agent-client-protocol` (ACP SDK), `click`, `platformdirs` (cross-platform paths)
**Constraints:** Python >= 3.12, Windows + Linux + macOS, agents are primary users (clean plaintext, no ANSI)

## 2. CLI design

### Commands overview

```bash
# Core
acpc prompt codex "fix the tests"                  # new session
acpc prompt claude "analyze repo" --model sonnet    # with model
echo "long prompt" | acpc prompt codex -            # stdin pipe
acpc prompt codex --input-file prompt.md            # from file
acpc prompt codex --last "follow up"                # resume last
acpc prompt codex -s SESSION_ID "follow up"         # resume by ID

# Options
--model MODEL        # ACP: session/set_model
--mode MODE          # ACP: session/set_mode
--permissions LEVEL  # controls request_permission responses
--cwd DIR            # ACP: session/new cwd
--json               # NDJSON ACP event stream on stdout
--quiet              # final text only on stdout
-o FILE              # write final text to file
--timeout SECS       # local timeout (exit 124)

# Management
acpc run ...                  # alias for prompt
acpc agents                   # list agents + install status
acpc sessions <agent>         # list sessions (ACP: list_sessions)
acpc install <agent>          # run install_command from TOML
acpc stop <agent>             # stop running sessions (SIGTERM → cancel)
acpc stop -s SESSION_ID       # stop specific session
acpc status                   # list running sessions
```

### Flag → SDK mapping

```
Flag                SDK call                      ACP method          Type
──────────────────────────────────────────────────────────────────────────────
(always)            spawn_agent_process()          [spawn]             protocol
(always)            conn.initialize()              initialize          protocol
--cwd               conn.new_session(cwd=)         session/new         protocol
-s ID               conn.load_session(id=)         session/load        protocol
--model             conn.set_session_model()       session/set_model   protocol
--mode              conn.set_session_mode()        session/set_mode    protocol
prompt text         conn.prompt()                  session/prompt      protocol
--permissions       client.request_permission()    request_permission  protocol
Ctrl+C / signals    conn.cancel()                  session/cancel      protocol
--json / --quiet    client.session_update()        session/update      local
-o / --timeout      -                              -                   local
```

### Permission levels

| Level | read/search/think/fetch | edit/execute | delete/move |
|-------|------------------------|--------------|-------------|
| `all` | allow | allow | allow |
| `write` | allow | allow | deny |
| `read` | allow | deny | deny |
| `none` | deny | deny | deny |
| `prompt` | allow | ask on stderr | ask on stderr |

Default: TTY detected → `prompt`. Non-TTY → `read` (exit 3 on denied).

### Agent TOML format

```toml
identity = "codex"
name = "Codex CLI"
author = "OpenAI"
run_command = "npx @zed-industries/codex-acp"
install_command = "npm install -g @zed-industries/codex-acp"
```

| Agent | run_command | install_command |
|-------|-------------|-----------------|
| Codex | `npx @zed-industries/codex-acp` | `npm install -g @zed-industries/codex-acp` |
| Claude | `npx @zed-industries/claude-agent-acp` | `npm install -g @zed-industries/claude-agent-acp` |
| Gemini | `gemini --experimental-acp` | `npm install -g @google/gemini-cli` |

## 3. Output & runtime contracts

### Streams

| Stream | Content |
|--------|---------|
| **stdout** | Agent response only. `text`: streaming chunks. `quiet`: final text. `json`: NDJSON |
| **stderr** | `[acpc]`-prefixed diagnostics (never pollutes stdout) |
| **`-o FILE`** | Final text to file. Not written on crash |

### Stderr messages

```
[acpc] session: 019cf2ca-b50f-7a13-ad67-14fe4db0e0ac
[acpc] resume: acpc prompt codex -s 019cf2ca-b50f-7a13-ad67-14fe4db0e0ac "follow up"
[acpc] tool: Bash "git status"
[acpc] permission: edit src/main.py → allowed
[acpc] still running... (1m0s)
[acpc] error: adapter not found: codex
```

### NDJSON schema (`--json`)

ACP `session_update` events pass through 1:1. Three acpc meta-events wrap the stream:
```jsonl
{"event": "session_started", "session_id": "abc123"}
{"sessionUpdate": "agent_message_chunk", "content": {"type": "text", "text": "..."}}
{"sessionUpdate": "tool_call", "toolCallId": "t1", "title": "Edit file", ...}
{"event": "session_ended", "session_id": "abc123", "stop_reason": "end_turn", "exit_code": 0}
```
Stream always ends with `session_ended` or `session_error`.

### `text` mode filtering

Only `agent_message_chunk` text goes to stdout. Tool calls, thinking, plans → stderr as `[acpc] tool:` lines.

### Crash behavior

| Mode | Stdout | `-o FILE` |
|------|--------|-----------|
| `text` | Partial (already emitted) | Not written |
| `quiet` | Nothing | Not written |
| `json` | `session_error` event | Not written |

### Exit codes

| Code | Meaning |
|------|---------|
| 0 | Success |
| 1 | Agent error |
| 2 | Usage error |
| 3 | Permission denied (non-interactive) |
| 124 | Timeout |
| 130 | SIGINT |
| 141 | SIGPIPE |
| 143 | SIGTERM |

### Signal handling

SIGINT/SIGTERM: `conn.cancel()` → wait 5s → `killpg(SIGTERM)` → wait 2s → `killpg(SIGKILL)` → cleanup sessions.json → exit.
SIGPIPE: default exit 141. Child spawned in own process group (`os.setpgrp` on Unix, `CREATE_NEW_PROCESS_GROUP` on Windows).

### Process management

Running sessions tracked in platform state dir (Linux: `~/.local/state/acpc/`, macOS: `~/Library/Application Support/acpc/`, Windows: `%LOCALAPPDATA%\acpc\`):
```json
{"019cf2ca": {"agent": "codex", "pid": 12345, "start_time": 1742123400.0, "cwd": "/repo", "started": "2026-03-16T10:30:00"}}
```
- `prompt` start → add entry with PID + process start_time (atomic write via tempfile + rename)
- `prompt` end (normal/crash/signal) → remove entry
- `stop` → read PID + start_time, verify process identity before sending signal, remove entry
- `status` → read file, verify PIDs (PID alive + start_time matches), clean stale entries

### `--last` scoping

Per-PPID files (`{state_dir}/last/{agent}.{PPID}`) avoid race conditions in concurrent use. Fallback: `{agent}.default`. Cleanup: 24h.

## 4. Architecture

```
src/acpc/
├── __init__.py      # version
├── cli.py           # click commands + generate-completion
├── client.py        # acp.Client subclass (session_update, request_permission)
├── runner.py        # spawn → init → session → prompt + signals + process group
├── agents.py        # TOML registry (built-in + user overrides)
├── sessions.py      # last_session_id + running map + ACP list_sessions proxy
├── output.py        # formatters + stdout/stderr contract
├── _completion.py   # shell completion install helper
└── data/agents/     # codex.toml, claude.toml
```

Cross-platform paths via `platformdirs`:
- Config: `~/.config/acpc/` (Linux), `~/Library/Application Support/acpc/` (macOS), `%APPDATA%\acpc\` (Windows)
- State: `~/.local/state/acpc/` (Linux), `~/Library/Application Support/acpc/` (macOS), `%LOCALAPPDATA%\acpc\` (Windows)

## 6. Risks

| Risk | Mitigation |
|------|------------|
| SDK API changes (v0.x) | Pin version |
| Adapters don't support `session/load` | `--last`/`-s` exits 1 with error, never silently starts new session |
| Adapters don't support `set_session_model` | Check capability, warn on stderr, proceed without |
| npx not available | Clear error + `acpc install` |
| Non-TTY permission hang | TTY detection, default `read`, exit 3 |
| Orphan adapter processes | Process group + signal cleanup |
| `--last` race condition | Per-PPID scoping |
| PyPI name taken | Publish v0.1.0a1 early |

Fallback if SDK unusable: raw JSON-RPC over stdio (Toad pattern).

## 7. Key decisions

| Decision | Why |
|----------|-----|
| ACP SDK, not raw JSON-RPC | SDK maintains protocol compliance, less code |
| plain click, not rich-click | Agents are primary users, no ANSI |
| TOML agent registry | Extensible without code changes (Toad pattern) |
| `prompt` as primary, `run` as alias | SDK-aligned naming |
| `--permissions` with 5 levels | Aligns with ACP tool kinds + Claude/Codex conventions |
| TTY-based permission default | Safe for agents (read), interactive for humans (prompt) |
| stdout = agent only, stderr = diagnostics | Pipe-friendly: `acpc prompt codex "task" \| jq .` |
| NDJSON = ACP passthrough | Native ACP events, agents parse natively |
| `stop` via PID, not ACP reconnect | ACP has no reconnect mechanism |
| Agent owns sessions | `list_sessions()` via ACP, minimal local state |
| Session ID + resume command on stderr | Like Claude Code, copy-paste ready |
| `--last` per PPID | No race conditions in concurrent use |
| Process group for child | No orphan adapter processes |
| PID + start_time for stop | Prevents killing wrong process on PID reuse |
| Atomic state writes | tempfile + rename, no partial reads |
| TOML = trusted local config | Same trust level as shell aliases. Documented in README |
| Adapter inherits full env | Documented. `--env` filtering deferred to v0.2 |

## Appendix: `acpc --help` cheat sheet

Included as click epilog. Full reference for agent discovery:

```
# acpc cheat sheet

## Quick start
acpc prompt codex "fix the tests"
acpc prompt claude "analyze repo" --model sonnet
echo "prompt" | acpc prompt codex -

## Multi-turn
acpc prompt codex "remember: X=42"
acpc prompt codex --last "what is X?"
acpc prompt codex -s SESSION_ID "follow up"

## Model & mode
acpc prompt codex "task" --model o3           # ACP: session/set_model
acpc prompt claude "plan" --mode plan         # ACP: session/set_mode

## Permissions (default: auto-detect TTY)
acpc prompt codex "task" --permissions all    # approve everything
acpc prompt codex "task" --permissions read   # read-only
acpc prompt codex "task" --permissions write  # read + write, no delete
acpc prompt codex "task" --permissions none   # deny everything (dry run)

## Output (stdout = response, stderr = diagnostics)
acpc prompt codex "task" --quiet              # final text only
acpc prompt codex "task" --json               # NDJSON ACP events
acpc prompt codex "task" -o result.md         # write to file

## Input
acpc prompt codex --input-file prompt.md      # from file
echo "fix" | acpc prompt codex -              # from stdin

## Process management
acpc status                                   # running sessions
acpc stop codex                               # stop by agent
acpc stop -s SESSION_ID                       # stop by session

## Other
acpc agents                                   # list + install status
acpc sessions codex                           # agent sessions (ACP)
acpc install codex                            # install adapter

## Flag → ACP mapping
# -s        → session/load          --model   → session/set_model
# --mode    → session/set_mode      --cwd     → session/new (cwd)
# --permissions → request_permission  Ctrl+C  → session/cancel
```
